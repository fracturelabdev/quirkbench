**母数が違う。** `z` は**識別力のあるケースだけ**から計算する（全モデル同値のケースは残差が全部 0 で情報を持たない）。`絶対` と `ばらつき` は**その次元の全ケース**の平均で、除外しない — 「全モデルが満点だった」もモデルの事実だから。
